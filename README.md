# 금속재료기사 CBT Pro v5

## v5 핵심 변경
- v4의 `2,000개 핵심 × 문구/선택지 셔플` 방식 폐기
- 실제 JSON에 서로 다른 지문을 저장
- 검증 핵심 2,000문제 + 수치조건/역산/응용/상황판단 문제를 실제 생성
- exact normalized stem 중복 0개 감사
- 문제마다 `concept_id`, `family_id`, `type`, `trust` 저장
- 세션 구성 시 같은 family와 같은 세부영역의 연속 출제를 억제
- 신규 우선 / 취약 우선 / 오늘 복습 / 오답 / 별표 / 실전 100문제 지원
- 1·3·7·14·30·60·120일 간격 복습
- 오답은 2회 연속 정답 시 해제

## 배포
GitHub Pages의 저장소 루트에 이 폴더의 **내용 전체**를 올리고 `main / (root)`로 배포합니다.

## 문제은행 생성 코드
`generate_bank.py`에 문제 생성식과 데이터 구조를 포함했습니다.

## 주의
이 문제은행은 Q-Net 공식 기출의 복제본이 아니라 자체 학습 문제입니다. 계산형은 코드에서 정답을 식으로 산출하고, 구조 검사를 통과한 뒤 JSON으로 저장합니다.


## v5.1 숫자 표기 수정
- 문제·선택지·해설의 Python식 과학적 표기를 제거했습니다.
- 예: `2.50 × 10⁻¹²`, `6.02 × 10²³`처럼 교재식 `×10ⁿ` 표기를 사용합니다.
- 문제 생성기 역시 재생성 시 동일한 표기 규칙을 유지합니다.
